# Dear.exe — Human Relay

Dear.exe is a quiet messaging experiment built around one simple question: what if a letter could only move when another person chose to carry it?

Write a private note, seal it, give it a destination, and let the journey unfold through human handoffs. Carriers never see the words. They only see where the letter is going, add an optional field note, and pass the relay forward. The app turns distance into a visible story: who carried it, which cities it touched, and how long it lived in the world.

## The product idea

**A letter can travel through people.**

Dear.exe combines the emotional weight of a physical letter with a lightweight digital passport. The message stays protected while the route becomes the shared experience.

## Product flow

1. Write a note worth carrying.
2. Seal it and choose the destination.
3. Share the relay passport with someone nearby.
4. Record each human handoff without exposing the message.
5. Follow the chain until the recipient opens it.

## What this project demonstrates

- A product concept with a clear emotional hook and simple interaction model.
- A cohesive stationery-inspired interface with an ink-navy, warm-paper, wax-red visual system.
- Local-first relay state with handoff history, route statistics, and recipient delivery state.
- Responsive Next.js UI across the desk, relay, mailbox, journey, profile, and letter views.
- Privacy-conscious interaction design: carriers can move the letter without reading it.

## Resume-ready description

**Dear.exe — Human Relay:** Designed and built a responsive Next.js messaging experience where private letters move through real-world human handoffs. Created a local-first relay model that records carrier chains, city counts, elapsed time, and privacy-safe field notes while keeping message content sealed from carriers.
